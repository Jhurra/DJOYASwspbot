# Terapia con Gi: rediseño de georgiacamarena.com (borrador v2)

Prototipo HTML estático del nuevo sitio de Georgia Camarena, con el diseño y la paleta de la plantilla Blocksy Consultant. Abre `index.html` en el navegador.

| Archivo | Contenido |
|---|---|
| `index.html` | Landing de Inicio |
| `conoceme.html` | Landing Conóceme |
| `servicios.html` | Landing Servicios |
| `agenda.html` | Landing Contacto (reserva con calendario y formulario) |
| `estructura.html` | Diagnóstico, mapa del sitio, estructura por landing y pendientes |
| `styles.css`, `main.js` | Estilos e interacciones compartidas |

Los textos marcados como **Pendiente** necesitan datos reales de Georgia: fotos, precio, duración, WhatsApp, testimonios y su historia.
